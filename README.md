# Student Result & Grade Calculator

A simple Python program that takes a student's name, roll number, and marks in five subjects, then calculates the total percentage, assigns a grade, and displays the final pass/fail result.

## Features

- Takes student name and roll number
- Takes marks for five subjects
- Calculates total marks and percentage
- Assigns a grade based on percentage
- Checks pass/fail status based on individual subject marks

## Concepts Used

- User input with `input()`
- Variables
- Type conversion using `int()`
- Arithmetic operators
- Conditional statements (`if`, `elif`, `else`)
- Logical operator (`or`)
- f-strings for formatted output
  
> This project was built while learning Python fundamentals and may be improved as I gain more experience.
